# Symbol

The 12-blade rotor with a circular cut-out (30° repeat, 256 × 256 master box).

- `ddcnorth-symbol-master.svg` — geometric master, black.
- `ddcnorth-symbol-black|midnight|white.svg` — single-ink versions; `-currentcolor.svg` for inline use.
- PNGs at 256, 512 and 1024px in black, midnight and white (transparent).
- Keep the symbol ≥24px. Don't add a container unless it is the app icon.
