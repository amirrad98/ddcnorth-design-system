# Logos

Outlined vector masters — no fonts, rasters or gradients. Each lockup comes in four inks: `-black`, `-midnight`, `-white` (white on transparent: looks blank on a white canvas) and `-currentcolor` (inherits CSS colour only when inlined; as an `<img>` it renders black).

- `ddcnorth-horizontal-*` — **the primary logo.** Default for web headers, documents and decks.
- `ddcnorth-stacked-*` — symbol above the wordmark, for square and narrow spaces.
- `ddcnorth-wordmark-*` — the name without the symbol, where the symbol already appears nearby.
- `ddc-horizontal-*`, `ddc-stacked-*`, `ddc-wordmark-*` — the parent **ddc** mark, same rules.
- `ddcnorth-hybrid.svg` — outlined ddc + live-text "north" (Inter Display). Only for changing the suffix; black ink.
- `ddcnorth-text.svg` — fully live-text approximation (Inter Display 800/400). Not a substitute for the outlined master; black ink.
