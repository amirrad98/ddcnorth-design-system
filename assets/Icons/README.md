# Icons

Five supporting icons, 64 × 64, 2px stroke in `currentColor` — as `<img>` they render black; use the `Icon` component to colour them.

- `clarity.svg` — 12 radial spokes: insight, focus.
- `cycle.svg` — 24 ticks: iteration, time, process.
- `direction.svg` — outlined arrow: next step, forward.
- `network.svg` — 12 dots in a ring: connections, systems.
- `signal.svg` — four rising bars: data, growth.
