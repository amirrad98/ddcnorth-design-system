# Card

A flat `surface-raised` panel for showing one asset or idea — a logo, a template, a short spec — with an optional caption.

- **Provide:** `media` (an image, `Logo` or template preview; shown in a 130px stage, contained), `caption` (one short line, e.g. "01 / Primary horizontal"), optional `children`, and `tone="reversed"` for a midnight panel.
- Lay cards in a three-column grid with `space-4`–`space-6` gutters (one column under 700px).
- No borders, shadows or rounded corners; separation comes from the surface change. On a reversed card use a white logo.
