# Note

An ice callout (`surface-field` with `ink-on-field`) for caveats, status and short explanatory notes.

- **Provide:** `children` — one or two plain sentences.
- Use sparingly, once per section at most. Ice is a supporting field: never put fine or small graphite text on it, and never use ice as a text colour on white.
- No icon, border or accent stripe.
