# Icon

The five supporting icons in the brand's radial / angular language, drawn inline so they take CSS `color`.

- **Provide:** `name` — `clarity` (12 spokes), `cycle` (24 ticks), `direction` (arrow), `network` (12 dots), `signal` (4 rising bars) — plus `size` (default 32) and `label` when the icon carries meaning alone.
- 64-unit grid, 2px strokes, butt caps, miter joins. Colour with `ink`, `ink-muted` or `midnight`; white on midnight.
- This is the whole set. Don't mix in rounded or filled icon libraries; if something is missing, draw it on the same grid with the same stroke, or use a word.
