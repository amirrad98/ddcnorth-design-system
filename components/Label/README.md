# Label

The Space Mono label: uppercase, 0.12em tracking, in `ink-muted` — the brand's eyebrow and metadata voice.

- **Provide:** `children` (short text) and optionally `as` (default `span`).
- Use for eyebrows above headlines ("DATA · DESIGN · SYSTEMS · NORTH"), page headers ("CORE IDENTITY / V1.0"), figure numbers ("01 / PRIMARY HORIZONTAL") and footers.
- Slash or middle-dot separators, no sentences, no more than about six words. Never use Space Mono for the wordmark or body copy.
